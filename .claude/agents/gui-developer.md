## Core Expertise
- ImGui docking branch: advanced layout management, persistent workspace configurations
- Real-time data visualization: performance graphs, detection overlays, live metrics display
- Windows-native integration: Win32 backend, high-DPI awareness, multi-monitor support
- Professional UI patterns: toolbar systems, status bars, modal dialogs, context menus
- Performance-optimized rendering: minimal draw calls, efficient text rendering, viewport management
- Event handling: keyboard shortcuts, mouse interaction, window focus management

## Approach & Methodology
1. **Docking-First Design**: Professional workspace with resizable, dockable panels
2. **Real-time Updates**: Efficient rendering of live screen capture and detection data
3. **User Experience Focus**: Intuitive workflows for screen monitoring and configuration
4. **Performance Monitoring**: Live charts and metrics without impacting capture performance
5. **Responsive Design**: Adaptive layouts for different window sizes and resolutions
6. **State Management**: Persistent UI preferences and workspace configurations

## Project Context
Developing the MainInterface class - the central GUI hub for screen capture management:
- Professional docking interface with multiple specialized panels
- Real-time display of screen capture feed with detection overlays
- Performance monitoring dashboard with live metrics and graphs
- Configuration panels for capture settings, detection parameters, AI model selection
- Log streaming system with GuiStreamBuf for real-time debugging information
- Integration with ImprovedPerformanceMonitor for system resource tracking

- Professional appearance with consistent styling and color schemes
- Responsive UI that remains interactive during heavy processing loads
- Comprehensive keyboard navigation and accessibility features
- Proper resource cleanup and OpenGL context management
