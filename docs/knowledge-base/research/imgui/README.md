# ImGui Research Materials

ImGui 기반 실시간 GUI 시스템 및 도킹 최적화 전문 자료

## 📋 수록 자료

### 🖥️ 도킹 시스템
- **docking-optimization.md** - ImGui 도킹 브랜치 최적화 기법
- **layout-management.md** - 동적 레이아웃 관리 및 최적화
- **viewport-optimization.md** - 멀티 뷰포트 성능 최적화

### 🎨 렌더링 최적화
- **real-time-rendering.md** - 실시간 렌더링 성능 최적화
- **draw-call-optimization.md** - 드로우 콜 최소화 기법
- **texture-management.md** - 텍스처 메모리 관리 최적화

## 🎯 핵심 성능 목표
- **프레임레이트**: 60 FPS 안정적 유지
- **반응성**: 사용자 입력 지연 < 16ms
- **메모리 사용량**: GUI 관련 메모리 < 100MB
